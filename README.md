# DayInMotion

## Overview

**DayInMotion** is an immersive Virtual Reality (VR) experience developed with Unity, focused on accessibility, wheelchair mobility, and interaction with everyday environments.

The project allows users to explore a virtual environment from the perspective of a wheelchair user, experiencing mobility challenges and interacting with objects and activities commonly found in everyday life.

Developed as part of the **TAIM 3DUI Challenge**, the project explores VR interaction techniques and accessibility-oriented experiences.

## Features

### Wheelchair Mobility
- VR wheelchair controlled through a joystick-based input system.
- Adjustable movement speed, acceleration, and rotation.
- Physics-based wheelchair movement.
- Movement behaviour adapted to flat surfaces and slopes.

### Interactive Environment
- Automatic doors triggered by player proximity.
- Functional elevators with animated doors.
- Interactive objects that can be grabbed and manipulated.
- Environmental triggers that respond to player interactions.

### Interactive Activities
- Sandwich preparation activity involving sequential ingredient selection and assembly.
- Interactive whiteboard supporting drawing and erasing.
- Activity progression through interaction-based triggers.

### Immersive Experience
- VR main menu and configurable movement settings.
- Contextual dialogue and thought bubbles.
- Typewriter-style text animations and audio feedback.
- Interactive triggers and scene transitions.

## Technologies

- **Unity 6**
- **C#**
- **Unity XR Interaction Toolkit**
- **Unity Input System**
- **OpenXR**
- **Universal Render Pipeline (URP)**

## Requirements

- Unity 6 (6000.0.38f1)
- Compatible VR headset and controllers.
- OpenXR-compatible VR runtime.
- Required Unity packages listed in `Packages/manifest.json`.

## Getting Started

1. Clone the repository
2. Open Unity Hub.
3. Add the cloned project.
4. Open it using Unity 6 (6000.0.38f1).
5. Ensure the required XR packages and OpenXR settings are configured.
6. Open the main menu scene and run the project using a compatible VR setup.
